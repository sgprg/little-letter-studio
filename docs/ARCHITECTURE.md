# Architecture

`src/content.ts` holds stable concept IDs, localized words/letters/sentences, UI text and palette names. `src/art.ts` holds original vector paths; region order determines occlusion. Thumbnails use the same source as the canvas.

`src/engine.ts` renders at 1600×1300 pixels in logical 800×650 coordinates. Pointer Events normalize mouse/touch/pen coordinates; coalesced samples preserve curves and interpolated pen pressure adjusts stroke width. Gesture bounds are measured once, and pointer-up retains contact pressure instead of producing a thick endpoint. A pen supersedes an unfinished touch stroke. Other simultaneous contacts, touches within 800 ms of pen activity, and broad touch contacts over 45 CSS pixels are ignored. Pen-only mode rejects all finger marks. These heuristics do not replace hardware palm rejection. Cancellation, blur and resizing discard the tentative stroke. Region clipping excludes overlapping foreground regions. Open decorative lines do not create separate fill regions.

`src/drawing.ts` defines serializable actions and saved-data validation; existing version-1 pictures remain compatible. History uses a cursor, with new actions truncating redo. The cap remains 300 actions and 30,000 sampled points. Committed paint, tentative paint and outlines are separate cached layers. Each animation frame draws only new stroke segments and composites the layers; historical strokes replay only on load or undo/redo. Completion and storage run after a gesture, outside pointer-move handling. This remains a WebView canvas, not a native PencilKit renderer.

Completion uses a 200×163 paint-coverage mask and visible-region map derived from the original paths. It requires at least 95% of the sampled interior of **each** visible region, excluding linework, pupils and paper. Intentional white marks count; erasing removes coverage; crayon grain does not count as missing color. This is a forgiving sampled estimate, not pixel-perfect certification. A local preference records which pictures have celebrated. Restoring an already completed picture marks it quietly; undo/redo never triggers a reward; explicit clear resets eligibility. The sparkle overlay does not receive pointer events or transform the drawing surface. Reduced-motion users receive a static message. Three quiet Web Audio sine notes are generated locally after gesture-based audio activation, with a saved mute preference and a silent fallback when Web Audio is unavailable.

`src/play.ts` manages the viewport-fitted play layout, feature-detected Fullscreen API and local sound. It enters automatically for native/installed display modes. The canvas retains its logical aspect ratio through a ResizeObserver; page overscroll is suppressed, while palette/tool/drawer scrolling stays usable. Unsupported or rejected browser fullscreen falls back to the play layout and explains Home Screen installation. The caregiver gate protects the app's exit control, but OS gestures and browser Escape cannot be locked by the app. Parent instructions describe Guided Access and App pinning.

`src/storage.ts` uses a versioned IndexedDB store and validates loaded records. A serialized save queue commits after completed gestures. Local preferences use localStorage. Failed loads do not silently replace the stored picture; the parent can explicitly clear it. The active picture remains usable in memory when writes fail. Export remains available. No network request is involved in saving.

`scripts/build-offline.mjs` hashes the complete static bundle and service-worker source, then generates a precache. Same-origin static responses are served from cache; cache identity includes scope so separate installations do not delete each other's caches. Updates wait for old clients to close, avoiding hot replacement during a stroke. Reopen after closing all tabs to activate an available update. Native apps skip service workers and use their bundled files.

Capacitor owns Android/iOS wrappers. Native PNG sharing uses Filesystem's cache directory and the OS share sheet; web export uses Web Share when supported or a file download. The exported image includes the selected letter and word. The temporary native file is deleted when sharing completes. No camera, microphone or contacts are requested. Android cloud backup is disabled for the app. Web/OS backup behavior outside the app remains under the user's platform settings.

Speech synthesis selects only a voice that the device reports as `localService`. No remote fallback is allowed. That property is a platform declaration, not a packet-level audit of a device's speech engine. Local voice availability and voice quality vary by OS and locale; bundled reviewed recordings are a beta milestone.
